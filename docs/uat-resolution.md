## Later visual and motivational additions

The app now uses Quicksand display text and Nunito body/control text, an optional skippable Buddy introduction, Light/Dark/System appearance, local XP and daily quests, progress-derived achievements, a saved custom avatar, genuine QR/copy/device-share controls and Plus/Family plan previews. Tutor Spotlight and demo pages provide a 3D greeting to try before choosing a companion. The current title is exactly **Narra - Your voice, your story!**; current copy avoids long typographic dashes.

Narra Arena and friend profiles provide richer sample highlights. Other profiles' XP, streaks, conversations and saved-word achievements remain explicitly fictional; the learner's row reads local progress. Following and cheers do not contact those people or publish externally. Plan interest stays local; no payment, subscription or email notification is created.

Timed speaking challenges are a separate real invitation flow, not simulated participation by a demo friend. A private Vercel Blob-backed room permits two actual named participants. They independently start the same prompt for 30 or 60 seconds, with a real countdown/timer and browser-recognized words. Results show words, elapsed time, WPM and the word-count goal. Missing participants remain waiting, without fabricated results.

The challenge API uses random room UUIDs, signed expiring participant passes, immutable per-participant records and server-side input validation. Server-only configuration is `CHALLENGE_SIGNING_SECRET` plus private Blob token credentials or Vercel OIDC/store identity. Room access expires after 24 hours and Blob objects use automatic TTL deletion. No audio or transcript is uploaded or stored by Narra for challenges; extra POST fields are ignored. Metrics are browser-reported and do not provide anti-cheat, pronunciation-quality scoring or semantic task assessment.

## QA boundary

The current integrated TypeScript check and Vite production build pass. A separate strict NodeNext check covers the challenge API/server utilities. Eight mocked-storage tests of the production challenge service pass, covering simultaneous joins, signed passes, timer/start rules, repeated results, expiry, word counting and transcript exclusion. These tests do not validate live Blob storage or real speech hardware.

Earlier browser checks are recorded in [qa-2026-11-16.md](qa-2026-11-16.md), including responsive layout, lesson completion, settings persistence, local community/XP, avatar, QR/copy and light/dark appearance. These are observed prototype checks, not stakeholder acceptance of every row above. Screenshots with the `narra-final-` prefix reflect that earlier pass, not a completed live pass for subsequent additions. The latest 3D tutor/demos, rich dictionary, Arena highlights and two-browser shared challenges still await the forthcoming integrated browser/deployed-API QA.

Device retesting should cover mic/camera permission grant/deny and late responses, recognition availability, actual capture, user-started/automatic subsequent voice playback, 3D motion/rendering, playback interruption, local stream/recording disposal, keyboard focus, four-tab navigation, EN/VI lengths, appearance, reload persistence, QR scan destination, clipboard fallback and user-invoked native sharing. Shared rooms additionally need deployed private Blob writes/reads, independent browser participants, polling, expiry and save retry checks. No live shared-room, real mic/camera hardware, phoneme-quality or payment test is claimed by this trace.

Authentication, live AI tutoring, academic pronunciation scoring, cloud identity/social data and scheduled notifications require connected services and their own validation. Local UAT notes do not mark those integrations complete.
